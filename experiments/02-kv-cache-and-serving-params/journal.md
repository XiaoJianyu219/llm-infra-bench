只带来 **+8.4%**,远不足以解释饱和。真正的瓶颈在别处。教训:参数扫描要
逐个单独改并量化各自贡献,不要凭架构直觉锁定"罪魁"。

**(b) 把 `use_cache=False` 的对照实验判成"坏了"。** 当时 prompt 长度只有
14 token,有无 KV cache 的差异被固定开销地板淹没,曲线看起来没有趋势。
把 prompt 加长后趋势立刻出现。教训:做对照实验前先估一下**信号是否高于
本装置的噪声地板**,否则测到的是装置而不是现象。

### Day 2 补记 · 换机至 4090D（2026-09-08）

主机 autodl-container-4bxw52um4a，GPU RTX 4090D。
显存侧核对：权重 16.65 GiB（相同）、KV cache 3.06 GiB / 22,256 tokens
（4090 为 3.05 GiB / 22,208），偏差 0.2%，小于噪声底，判定为一致。
每 token 开销 144.2 KiB，与 4090 及理论核算一致（第二台机器的独立验证）。

**跑 4090D 并发扫描前的预测**（按 roofline 模型，带宽相同、算力低约 11%）：
- conc 1 TPOT：17.3 → 17–18 ms（带宽支配区，应几乎不变）
- conc 1 吞吐：0.42 → 约 0.42 req/s
- conc 64 吞吐：3.52 → 3.1–3.3 req/s（算力支配区，应低 6–12%）
- conc 64 TPOT：32.4 → 35–37 ms
- 显存峰值：基本不变

若第一项不变而第三项明显下降，则 roofline 结论获得跨硬件验证。
若两者同比例下降，则模型不完整，需重新分析。
